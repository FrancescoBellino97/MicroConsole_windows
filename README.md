# MicroConsole (Windows) project

## Scope
The goal of this project is to create an emulator of GameBoy that can run on Windows.

## Documentation
The reference documentation can be found at [PanDocs](https://gbdev.io/pandocs/).

## How it works
The project has the following structure:
 - **core**, here there is the application code
 - **lib**, here there are the SDL2 libraries for graphic and audio
 - **tools**, here there is a memory estimation script
 - **makefile**, this is the main makefile
